## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/SanskritiPandey28/AI-Lab-Python.git
```

### 2. Navigate to the project directory

```bash
cd AI-Lab-Python
```

### 3. Create and activate a virtual environment

```bash
python -m venv .venv
```

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

### 4. Install required libraries

```bash
pip install numpy scikit-learn
```

Some programs may require additional dependencies depending on their implementation.

### 5. Run a program

Navigate to the respective lab folder and execute the Python file:

```bash
python LAB7/ForwardChaining.py
```

For C and C++ programs, use an appropriate compiler such as GCC or G++.
